# Cohesive.Machines.Transitions

Optional entity bindings for [Cohesive.Machines](../Cohesive.Machines/README.md).
Typed discriminator and predicate authoring project exact machine references into the existing
TransitionMachineLinkCatalog. The integration introduces no storage, runtime or commit protocol.
See the Machines README for examples, ownership rules, supported predicate expressions and proof limits.
